# StarChat

Android-приложение для общения с AI-моделями через Starimg API. Переключайтесь между моделями, ведите несколько чатов и следите за расходами — в одном приложении.

## Возможности

- Потоковый чат с AI-моделями
- Поиск, выбор и сравнение моделей
- Текстовые запросы и изображения — для моделей с поддержкой фото
- История чатов: переименование, папки и теги
- Редактирование и повторная отправка сообщений
- Библиотека промптов и пользовательских агентов
- Статистика токенов и расходов
- Новости Starimg в приложении
- Импорт и экспорт настроек

## Безопасность и конфиденциальность

- API-ключ и Access token хранятся на устройстве в зашифрованном виде.
- Чаты, настройки и статистика сохраняются локально.
- Для получения ответов запросы отправляются в Starimg и выбранную AI-модель.
- Приложение не содержит рекламы, вирусов или троянов. Исходный код открыт и доступен в этом репозитории.

## Установка и настройка

1. Скачайте APK со страницы [Releases](../../releases) и установите его.
2. Если Android предупредит о приложении из неизвестного источника, это стандартное предупреждение для APK, установленных не через Google Play. Продолжайте, только если скачали файл со страницы релизов этого репозитория.
3. Откройте **Настройки** и укажите API-ключ и Access token.
4. Выберите модель и начните чат.

## Требования

- Android 8.0 или новее
- Подключение к интернету
- Действующий API-ключ Starimg
